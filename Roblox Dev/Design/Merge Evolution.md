# Merge Evolution (T100)

Three tiers per familiar, written overnight 2026-10-29. Tier 1 is the base model; **tier 2 and tier 3 each add one body-attached feature with a reason**, and the figure grows to 115 percent and 130 percent. Features never use the rarity kit shapes (halo ring, floating shards, spike fan) of [[Rarity Silhouettes]], so a Legendary at tier 3 still reads as two different things. Rule: [[Character Bible Rules]]. Specified only: no 3D model contains these features yet, and the look is UNVERIFIED. Per-familiar strips: `Assets/Characters/Merge/<Name>_tiers.png`, `_tiers_sheet.png`. Built by `tools/merge_tiers.py`.

## Open decisions for the user
1. Merge is three of the same pet into one tier up (see the [[Game Design Doc]]); the plan has only 3 tiers, so tier 3 is the final look. Is 130 percent size at tier 3 enough on the 2 by 6 grid, or should it be larger?
2. Features here are placeholders in words; the 3D work (new model parts, bone weights for the two-bone figures) is a later step and may change which features are cheap.
