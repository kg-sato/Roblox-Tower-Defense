# UI Screens

Wireframes for each game screen, drawn with the Excalidraw plugin (open source, AGPL-3.0). Review: [[Research/GUI Maker Tools Review|GUI Maker Tools Review]]. Rules: [[Research/UI Design Playbook|UI Design Playbook]], [[Research/Low-End Device Playbook|Low-End Device Playbook]].

## How to use
1. New drawing: command palette (Ctrl+P) -> "Excalidraw: Create new drawing". It is saved in `UI/Drawings/` and, on every save, a **PNG copy is written next to it** (same name, `.png`) so Claude can read it.
2. Draw the screen **phone-shaped (landscape, about 16:9)**. One box per button or label, a short note for what it does and its states (normal, pressed, locked, empty).
3. Link it here, then ask Claude to build or update that screen in Studio. Claude screenshots the result for comparison.

## Rules to follow in every drawing (see the playbooks)
- Keep important buttons away from the phone's bottom-left and bottom-right corners (default mobile controls) and out from under the top bar and notch.
- Mark what stays visible on a menu open (nothing from the HUD should overlap a full-screen menu).
- Say which numbers use the number-format setting, and which effects honor Flashes and Particles settings.
