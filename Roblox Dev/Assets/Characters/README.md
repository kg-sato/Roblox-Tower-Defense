# Character portraits (2026-10-25)
Eight original characters of the merge chain (see `Game Redesign - Merge Academy.md`, data in `VFX/Roster.luau`). Generated locally with
ComfyUI + FLUX.1 schnell (Apache 2.0) from our own text prompts (`VFX/sfx/gen_roster_art.sh`), 3 variants each, picked by
`VFX/verify_roster_art.py` (subject coverage, margin, dominant hue vs roster colour) plus a visual check. Backgrounds keyed out to transparent PNGs, 512 px.
Picks: Pip s11, Moss s21, Lumo s31, Rook s42, Vesper s151 (regenerated: the first Vesper was navy like Mirelle), Aurel s61, Mirelle s71, Solenne s82.
Not uploaded to Roblox. Style is consistent but they are AI-generated 2D portraits: expect to redraw or touch up before a public launch, and check that Roblox accepts them.
