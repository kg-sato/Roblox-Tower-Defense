# Bloons TD6: upgrades and path variety (T001)

Question: how does BTD6 structure tower upgrades, and how does it make each map feel different?

## Upgrades (what to take from it)
- Each tower has three upgrade paths. A tower can draw from only two of them, and only one path can go past tier 2 (one path reaches tier 5, the other stops at 2). Notation reads top, middle, bottom, e.g. 5-1-0. Source: [Bloons Wiki, Upgrade](https://www.bloonswiki.com/Upgrade) (page found in search; full page returned 403 to the fetch tool, so this is from the search summary).
- Tier-5 upgrades are capped so one tower can hold a specific path's tier 5. Source: [Bloons Wiki, Path 3 upgrades category](https://www.bloonswiki.com/Category:Path_3_upgrades_in_BTD6) (search summary).
- Paragons are a sixth tier, added in version 27.0 per the search summary; they combine elements of all three tier-5 upgrades. Source: [Bloons Wiki, Upgrade](https://www.bloonswiki.com/Upgrade) (search summary).
- Crosspathing (mixing two paths) is guided by a chart. Source: [Bloons Wiki, Crosspathing/Alchemist](https://bloons.fandom.com/wiki/Crosspathing/Alchemist) (search summary).
- Design take for us: a small number of clear identities per tower, a hard limit on how deep one path goes, and a late "combine all" tier. This matches the T318 upgrade-path task.

## Path variety (what to take from it)
- Lost Crevasse: asymmetric split path where lanes diverge widely, so placement matters for range. Source: [Bloons Wiki, Lost Crevasse](https://www.bloonswiki.com/Lost_Crevasse) (search summary).
- Park Path: a curvy track that suits area-of-effect towers. Source: [Sportskeeda, all BTD6 maps ranked](https://www.sportskeeda.com/mobile-games/all-bloons-td-6-maps-ranked) (opinion ranking, search summary).
- Infernal: tight map, scarce tower space, two paths only. Source: [Bloons Wiki, Infernal](https://bloons.fandom.com/wiki/Infernal) (search summary).
- Dark Path: added in version 39.0 as a twist on Park Path. Source: [Bloons Wiki, Dark Path](https://bloons.fandom.com/wiki/Dark_Path) (search summary).
- Design take for us: each stage set gets one signature path shape (split, tight, curvy, double-back) rather than one shared layout. This matches T293 to T294.
