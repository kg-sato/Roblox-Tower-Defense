# UI Rework 2026-10-28

Why: the user's list ([[User Inputs]], 2026-10-28): roll bar redesign, a real loading screen and a start menu, useless left buttons and generic UI, a low-effort skill tree, a useless progression tab, badly placed buttons, ugly streak and gem indicators. Then: "everything is still too generic, all the buttons are the same uniform look; research very unique UIs and implement their ideas". Captures in `UI Rework 2026-10-28/` (before: `hud_start`, `hud_game`, `hud_tree`, `hud_prog`; after: the rest). Code: `Studio_Export/GameClient.luau` (backup of the old one in `ServerStorage.GameClient_backup_HUDv1`), `Studio_Export/LoadingScreen.luau` (ReplicatedFirst). Look and feel: **UNVERIFIED** until the user plays it.

## Research behind the object look
- **Inscryption:** every control is a physical object (a bell ends the turn, candles are lives) ([DiGRA paper on Inscryption's remediation](https://dl.digra.org/index.php/dl/article/view/2474); [Game Developer interview](https://www.gamedeveloper.com/design/how-game-jam-sacrifices-became-inscryption): card art was fretted over for legibility).
- **Persona 5:** one main colour with no sub-colours except HP and MP, central lines that pull the eye, angle and contrast changes that give context, a 3D model that spins and lands in a pose in the menus ([Siliconera, Atlus's own talk](https://www.siliconera.com/atlus-reveals-design-secrets-behind-persona-5s-distinctive-ui/)).
- **Darkest Dungeon:** gothic, hand-drawn heavy lines and a mood set from the first screen ([GameSpot on its gothic sensibilities](https://www.gamespot.com:443/articles/the-gothic-sensibilities-of-darkest-dungeon/1100-6424880/)); Victorian UI kits on itch.io use brass, rivets, plates and parchment ([Victorian Button Pack](https://abstergodesign.itch.io/victorian-button-pack), not bought).
- **Roblox loading screen rules (official):** LocalScript in ReplicatedFirst, `RemoveDefaultLoadingScreen()` after our gui is parented, a minimum display time, then wait for `game.Loaded` ([Loading screens](https://create.roblox.com/docs/players/loading-screens)).

## What changed
| Area | Before | After |
|---|---|---|
| Loading | Roblox default, then a plain card | ReplicatedFirst screen: violet backdrop, drifting motes, crown in two counter-rotating rings, gold progress line from real loading (asset queue + `game.Loaded`), themed status lines, tips every 4 s, "Welcome, <name>", fade |
| Start menu | small centred card | left: crown, GUARDIAN / GRID logo, tagline, big PLAY with sword; right: the first Legendary familiar turning on a glowing pedestal (ViewportFrame) |
| Layout | text rail top-left, START WAVE + AUTO bottom-left, ULT square | trainer card + purse top-left; dock left-middle; stage sign + crystal bar + streak top centre; roll bar bottom centre; START WAVE + ULT bottom right |
| Stage | pill | iron street sign hanging on chains, swaying 2.5 degrees |
| ROLL | glass pill | tarot card tilted 9 degrees on a brass plate; straightens and lifts on hover, flips on press; dims when unaffordable |
| START WAVE | glass pill | brass bell on a plate; the bell swings when rung |
| ULT | square | pocket watch; a glowing hand sweeps once round as it charges |
| AUTO / QUICK | rail text buttons | brass dials on plates, turn a quarter and light a lamp when on (QUICK moved from the rail into the roll bar) |
| Dock | 3 text buttons | crimson wax seals with painted icons (Skill Tree, Progression, Settings), badge on the seal |
| Coins / gems | faint text pills | brass plates with large icons breaking the edge |
| Streak | gold text line | flame badge: "x10", "GEMS x3.00", pops on each new perfect stage |
| Skill tree | 3-letter codes, touching hexes | painted icons per skill, spaced hexes with path lines (gold when both ends owned), glow and stars, detail card with icon, level pips, "Now > Next" |
| Progression | text list | Trainer Road: 25 level cards (claimed / NEXT / locked) with gems, skill point, luck, AUTO ROLL at 3 and milestone chests every 5; luck chip shows live Legendary and Epic odds |

Art: 19 UI Kit icons + a new flame icon, and 7 object images (`UI Kit/art/out/obj_*.png`: tarot, bell, watch, seal, sign, dial, plaque, made with local ComfyUI in the project's dark-fantasy style), all uploaded 2026-10-28 with the user's OK for our own art; ids in `UI Kit/art/ids.json` and the `OBJ` table in GameClient.

## Checked (Seen in Play, mouse clicks through the MCP)
Loading to start menu to PLAY; HUD in a real run to stage 11 with AUTO on (streak badge x10 showed); skill tree opens with icons, lines, detail, buy button; Progression road opens; ROLL card hover. Bugs fixed on the way: a start-menu local named `shade` hid the colour helper and broke the skill tree; `ClipsDescendants` drew the ULT fill square; UIPadding shifted glass skins; plates covered counter text.

## Not checked
Phone layout (code path exists, not emulated), the bell, card flip and dial animations frame by frame, buying a skill and claiming a level in the new screens, a second player, low-end frame rate with the extra images. The Featured familiar halo still reads a little flat; the start menu has no Settings entry (the panel lives in the HUD).
