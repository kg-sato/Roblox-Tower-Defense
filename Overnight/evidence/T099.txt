PASS (rarity kit defined, drawn for all 12 and machine-checked; shown as 2D overlays, not built into the 3D models, and the look is UNVERIFIED by the user)
Built: tools/rarity_silhouettes.py (Pillow, numpy, scipy; run with the Hunyuan3D venv). On each familiar's textured front still (backdrop keyed out) it adds shapes behind the figure: Common = base only; Rare = halo ring behind the head; Epic = Rare + 2 floating diamond shards at chest height; Legendary = Epic + a fan of 5 spikes behind the head and 4 orbiting shards. Tints blue, purple, gold are secondary. Design note: Roblox Dev/Design/Rarity Silhouettes.md.
Outputs in Roblox Dev/Assets/Characters/Rarity/: 12 files <Name>_rarity.png (4 colour variants over their 4 black silhouettes), _rarity_sheet.png, _silhouette_sheet.png, _rarity_report.txt (copy in Overnight/evidence/T099_report.txt).
Machine checks (all 12 ok, "familiars: 12 problems: 0"): base silhouette is a subset of every variant (the kit never covers the figure); IoU against the base falls at each rarity (Rare 0.73 to 0.89, Epic 0.53 to 0.74, Legendary 0.30 to 0.54; limits 0.93, 0.80, 0.55); floating shards 0 / 0 / 2 / 6 (shard = piece of 40 pixels or more touching none of the figure); bounding-box width rises at each step.
Fixes made along the way, disclosed: the first run failed on a measure I had chosen badly (counting connected pieces, which the base's own specks and the spike fan merged); I replaced it with the floating-shard count, which measures what the rule means. I also enlarged the canvas (420 to 560 px) because orbit shards were clipped, enlarged the Epic shards and moved the Legendary orbit shards so they stay detached. The IoU limits were not loosened.
Visual check: I viewed the full colour and silhouette rows for Moth-Lantern only (the 12 were checked by numbers, not all by eye). There the ring, the two shards and the spike fan read clearly in black and white.
Limits: this is a generic 2D kit placed on stills, not per-familiar design and not built into the 3D models; each familiar has a single rarity in the cast, so which kit ships on which model is an open decision (see the note); Legendary reaches 2.4 to 4.8 times the base width, probably too big for a tower-defence tile; "reads at game size" is not tested here (T087 did that for the base cast); colour-blind safety of the three tints is not tested.
