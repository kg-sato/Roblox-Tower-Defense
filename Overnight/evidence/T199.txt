PASS WITH A GAP (function installed in Studio, mirrored in Studio_Export/Config.luau, tested)
Config.nextBestSkill(levels, sp) returns the id and cost of the cheapest node that is reachable (a neighbour is owned), not maxed and affordable; ties go to the node listed first in Config.TREE; nil when nothing can be bought. Tests (7 new in Rules.test.luau, Studio Edit mode, "PASS Rules: 45 of 45"): no hint with 0 points; the hint is a neighbour of Start and costs 1; a maxed node is never suggested; unreachable nodes (Heavy, Mega) never; a node dearer than the points held is skipped; nothing when everything is maxed.
Gap: the hint itself is not shown in the skill tree (the screen belongs to the loading-eye chat, told the function name). "Useful" is only "cheapest": it does not weigh what a node does.
