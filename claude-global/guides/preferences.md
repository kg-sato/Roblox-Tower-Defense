# Task-specific preferences

Distilled from my Codex memory summary. Apply when the task matches. Treat as preferences I've shown, not rules to invent beyond.

## Schoolwork (STEM, calculus, physics)

- Use the actual rubric, criteria, instructions, tables, and graph slots before predicting anything.
- Inspect the whole document and every named checklist or sheet before saying a page or requirement is missing. Render PDF pages if needed. Resolve page ambiguity first.
- Step-by-step, organized, concise, complete. Teach the concept first, then edge cases. If I say I don't get the steps, give one short step at a time.
- Visuals (vector diagrams etc.): clean and readable, and actually validated. Have a raster or preview fallback if SVG rendering fails.
- Academic writing: preserve my voice. Emails to teachers stay respectful and accountable.

## Applications and evidence

- Prefer primary and local supporting documents over chat summaries. Keep confirmed vs inferred attribution explicit.
- PDFs: verify visually before delivering.

## Recurring "Informed" brief

- Lead with at least two verified Canadian opportunities when available (value, eligibility, location, deadline, direct link).
- Minimize personality-driven politics. Keep the exact four-section layout. Disclose source gaps.
- If an image can't be verified, write `Visual unavailable today` instead of using uncertain imagery.
- Name the actual sources and tools used. Don't claim a skill's engine or authenticated feeds ran if you only read its files.
